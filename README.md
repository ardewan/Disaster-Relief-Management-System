# Disaster-Relief-Management-System
The Disaster Relief Management System is a full-stack web application designed to support NGOs and governmental agencies in coordinating disaster response efforts. Built using Node.js, Express.js, OracleDB, and a frontend stack of HTML, CSS, and JavaScript, the system facilitates efficient management of donations, volunteers, relief centers, and disaster-related data. It features a robust Oracle-backed relational database with a normalized schema and supports advanced SQL functionalities, including joins, aggregations, nested queries, and division operations. The application exposes a set of RESTful APIs that power a responsive frontend, enabling dynamic data visualization and real-time analytics. A custom deployment script ensures seamless setup with dynamic port allocation and Oracle client configuration. This system streamlines logistical workflows and provides critical insights to enhance the effectiveness of disaster relief operations.
